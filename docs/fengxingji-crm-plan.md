# 蜂行记（CRM 替代）方案备忘

> 状态：方案已定稿，迁移与表单建设进行中（更新至 2026-09-03）。流程图与待确认项见钉钉文档《蜂行记 · 客户全生命周期流程（待销售团队确认）》。

## 背景

- 旧 CRM 无 API、无法回写；老板要求看到每个节点详情（沟通产品、对接人、意向），新建 OA 审批单「蜂行记」作为采集入口。
- 存量数据（旧 CRM 导出，目录 `~/Documents/作业/丹弗/地图/CRM`）：
  - 客户：国内终端（私海）8021、公海 5873（**疑似导出截断，CRM 显示 13000+，待核实**）、国内代理商 119、海外终端 230、海外代理商 65；合并去重约 14000+。
  - 跟进记录 5669 条（2022-11 ~ 2026-09），匹配客户率 99.51%，剩余 28 条孤儿放弃。
  - 跟进图片 5070 张带签名 OSS 直链（有效期至 2026-12-01），计划批量下载存**钉盘**，不落服务器。

## 核心架构（四层分工，2026-09-03 定稿）

| 层 | 职责 | 载体 |
|---|---|---|
| 采集层 | 销售所有动作的录入（新建客户/写跟进/拜访签到/商机/合同/订单），带审批留痕和时间戳 | 钉钉 OA 审批单 |
| 原始事实层 | 审批单实例 = 不可变事件流（谁、何时、对哪个客户、做了什么） | 钉钉（系统同步副本入 raw_approvals） |
| 逻辑层 | 当前状态计算（节点/归属/掉保/公海私海）、权限规则、姓名归一 | 我们的系统 |
| 展示层 | 客户看板、客户 360 时间线、地图分布、价值排行、员工视角分析 | 我们的系统（只读查询） |

**核心原则：钉钉存事实快照，系统存当前状态。** 状态永远可从事件流重算；钉钉实例创建后不可改（官方限制），所以表单里的字段都是"初始值/历史快照"。

关键结论：

- **公海/私海归属、掉保时间、退回次数等状态**：只在系统 `customers` 表，系统每晚定时计算；不进钉钉表单。
- **负责人**：表单里存"初始归属"（**用单行输入框存姓名，不用成员选择组件**——成员组件对写入方要求苛刻，钉钉自家 agent 都写不进）；系统里维护"当前负责人"（姓名→userid 归一化映射），捡回/掉保时系统变更。
- **权限**：钉钉侧关联选择只暴露客户名称；"私海仅归属人可看跟进记录、公海全员可看"在我们系统的客户看板做行级权限。
- **时间戳**：全部依赖审批单的创建/审批通过时间；掉保 = 最近一次审批通过的跟进事件 + N 天。不用 AI 表格（无审批流、无"审批通过"时刻、无定位打卡组件）。
- **客户跟进状态**（初步接触/方案报价/…/丢单）：表单保留初始值字段，后续流转由蜂行记事件驱动、系统计算更新。

## 表单设计

### 「客户新增登记」审批单（processCode: `PROC-C20D9C1D-0D64-4F44-88FC-72103F36D29D`）

- 审批表单（非数据表单——数据表单无实例 API/不可被引用），流程自动通过。
- 「功能」单选：新建客户/新建商机/写跟进/新建合同/新建订单，显隐规则展开对应字段组。
- 客户类型 4 类（国内企业客户/国内代理商/海外终端客户/海外代理商），各分支字段见表单（约 60 控件，含联系人字段组）。
- 选项口径注意：跟进状态选项用**反斜杠** `初步接触\拜访`（与 CRM 数据一致，勿改）；标签-客户类型选项"国内代理商客"缺"户"字（待改）。
- 公海不是类型，是系统侧状态，不在表单体现。

### 「蜂行记」（设计中）

- 定位：所有跟进/节点/详情的唯一日常入口；员工日常只填这一张。
- 关联客户组件指向「客户新增登记」实例（搜索选择；搜不到则先提交客户新增登记）。
- 拜访类事件含定位打卡（替代现有 v2 用车里程&签到单），详情类可当天后补。

## 迁移方案

- **客户主档灌入**：通过审批开放接口逐条创建「客户新增登记」实例（官方确认此路径）。我方的 Node 脚本（`backend/scripts/migrateCustomersToDingTalk.ts`）已写好字段映射/渠道归一/标签拆分/姓名→userid 映射/断点续跑，但老接口 `processinstance/create` 对该模板持续报 810003（新版设计器表单兼容性问题，排查后未定位到具体组件），新接口 `/v1.0/workflow/instances` 报 `corpId can not access`（已开 Workflow.Instance.Write 权限仍不行）。**当前改用钉钉官方 agent 执行灌入**（已验证可写实例，但写不了成员组件——故负责人改文本字段）。
- **导入版数据文件**（CRM 导出目录下）：
  - `国内企业客户_导入版_8021.xlsx`：严格对齐 OA 字段；渠道全角括号→半角；区域去"华南-/华东-"前缀；标签拆三列（产品意向/客户类型/意向，"高意向"→"高"）。
  - `公海客户_导入版_5873.xlsx`：同上 + 8 个 `_` 前缀参考列（旧数据ID/最后负责人/退回公海信息等，只进系统库）。
- **迁移期必填放宽**：联系人四字段（0% 有值）、客户所属区域（40%）、获取渠道（58%）、刀具柜安装地址（69%）、法定代表人/公司地址（94%）、负责人（98%）等需临时改选填，灌完再恢复。
- **跟进记录 5669 条**：不进钉钉，直接入系统库，与新跟进拼成完整时间线。
- **图片**：批量下载存钉盘（2026-12-01 链接过期前完成）。
- **系统初始化**：私海 → `customers.owner`=负责人；公海 → sea=公海 + 最后负责人/退回信息留档。
