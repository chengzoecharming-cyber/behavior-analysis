# PRD-001 历史拜访数据补录

> 状态：🔵 进行中 ｜ 创建：2026-10-19 ｜ 归属：数据地基

## 背景

系统此前只有 2026-06-01 之后的拜访数据。v1 表单「（旧版报销用）用车里程登记&客户签到」实际 2024-09-13 就有数据，需要全量补录以支撑历史分析与后续 CRM 三方联动。

数据分两段，获取方式不同：

| 段 | 时间范围 | 获取方式 | 状态 |
|---|---|---|---|
| API 段 | 2025-10-15 ~ 2026-05-31 | 钉钉 listids + 实例详情（365 天限制内） | ✅ 已入库 |
| Excel 段 | 2024-09-13 ~ 2025-10-15 | 管理后台手动导出 Excel（API 盲区） | 🔵 地理编码中 |

## 已完成（API 段，2026-10-16）

- 8418 条拜访 / 3660 张审批单入库，0 重复（唯一索引 + 存在即跳过 + 批内去重）。
- stops 3168 个 user+date 全部补算成功。
- 导入用 `SKIP_DERIVED_RECOMPUTE=1` 隔离高德配额消耗；routes 用 `fillMissingRoutes N` 分批限流补算。
- 生产备份：`backup-before-history-import-20261016-1453.sql.gz`。

## Excel 段方案与进展

- 源文件：`~/Documents/作业/丹弗/地图/`（2 个导出文件，多 sheet 按模板版本划分；注意 openpyxl 需 `reset_dimensions()`，否则读到假的空 sheet）。
- 解析已验证：289 张重叠单与 API 记录逐字段一致（时间/地址/客户名 289/289）。客户名归属规则与 v1 API 解析一致（两站之间填的客户属于下一站）。
- 数据量：7363 张单去重后，排除撤销与 0 打卡点单 → **7119 张有效单、18747 个打卡点、9139 个唯一地址**。
- 与生产库重叠 289 张自动跳过；`source_detail='excel-export'` 标记来源；归日口径复用「审批单级归日」。
- 地理编码：第一批 4000 个完成（成功 2485 / 失败 1515，短地名为主）；短地名借同单城市前缀救回 68 个。
